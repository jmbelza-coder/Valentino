***Project Tree Planting:Replant the Lost***

**II. Problem Statement**

Deforestation is a major contributor for climate change. And with that fact how can we revert the
changes of deforestation because it’s not avoidable but it is revertable. Because without the
reversion of the changes of deforestation it may be too late to help our planet. By reverting the
deforestation we can majorly reduce the climate change to a minimum.

**III. Objective**

The objective of this project is to plant an amount of trees for every tree cut down. We want to
achieve this by planting five trees for every tree that was caught in deforestation.

**IV. Planned Feature**

The following is what our project will be able to achieve
● It will increase the amount of trees in the environment
● It will provide homes for animals
● It will help in the prevention of climate change
● It will make reduce air pollution

**V. Planned Input**

Output:How many trees did you cut down
Input: There was 300 trees cutted down
Output: Then you must plant 1500 trees in return

**VI. Example**

Show “How many trees did you cut down”
Input Trees_cutted
Trees_planted equals Trees_cutted times five
Show "Then you must plant", Trees_planted, "in return"
